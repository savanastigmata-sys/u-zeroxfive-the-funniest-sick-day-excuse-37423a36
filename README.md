A program that writes one funny sick-day excuse (149 characters) to entry.txt. One line, under 200 characters, that someone could send to call in sick: a back gone out, a cat on the chest, and a tiny landlord collecting rent.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 -P -s main.py
```
